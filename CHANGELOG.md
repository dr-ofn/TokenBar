# Changelog

## 9.0.2 — 2026-11-24
Patch release: fixes for defects a multi-model review of the published 9.0.1 found and reproduced.

- **Invalid characters no longer cost calls.** On the Mac a log line holding invalid UTF-8 or a lone surrogate escape was dropped; it is now read with the bad part as U+FFFD, so the Mac and Windows count the same calls. On Windows one such line could wipe the counts of every other file scanned in the same pass; it no longer can. Windows also handles such names the same way everywhere: a Zed thread with invalid bytes is read instead of dropped, a Qwen Code session no longer gets a second adjustment that counted it twice, a Cline, Roo or Kilo task folder with such a name no longer loses its calls, and a Devin transcript with such a name no longer leaves its database rows counted twice.
- **oh-my-pi and Pi session headers.** The header is the first non-blank line (a BOM and blank lines are skipped, and it may be long) on both systems and on every read, so a header written with spaces, after a blank line or past the first 120 bytes no longer falls back to the file name, and two sessions with identical call lines are no longer merged into one.
- **Windows: oversized Codex archives.** A `.zst` archive past the size limit still counts the calls read before the limit instead of losing all of them.
- **Zed.** On Windows a thread that cannot be unpacked is named as a problem instead of being skipped silently, with the Mac app's 256 MiB limit; on the Mac the message is the thread id and a sentence in your language instead of an internal error with a temporary path.
- **Windows: Claude Code cost records.** A record with an impossible start time no longer triggers a repair on every start.
- **Windows: prices.** After a failed price fetch a restart no longer delays the retry from one hour to six; switching **Offline** off fetches prices right away; a damaged cache timestamp or failure time no longer crashes the app; a price download is cut off after 120 seconds.
- **Mac: Antigravity and Zed.** Their databases are compared by an inode, size and nanosecond-time stamp like opencode's, so a clock set back or a restored backup no longer hides new calls. After the update each database is read once more, without counting anything twice.
- **Mac: messages in your language.** Source warnings, scan errors and `tokenbar-cli` messages follow the interface language (`TOKENBAR_LANG=en` no longer prints Turkish), and command-line usage errors go to stderr.
- **Mac: `model-aliases.json`.** One non-string item in `localProviders` no longer drops the whole list (as on Windows).
- **Docs.** `docs/HARNESSES.md` says which reader families can start a new tool in `custom-sources.json` (five) and which must use their built-in tool's id (the other 23). The Windows README and About box describe `--refresh-prices`, `--prices-now` and `--offline` as they behave.
- **Release.** `scripts/release.sh` always builds a universal app and checks arm64 + x86_64 before and after zipping. One version rule for tags (`vX.Y.Z` or `vX.Y.Z-pre`; files say `X.Y.Z`; zips are named from the tag), shared by the audit, `release.sh` and the Windows workflow. The audit also refuses a tag that already exists on GitHub. CI now runs the Windows test suite, including the release-script tests, on the macOS job.

## 9.0.1 — 2026-11-23
Patch release: fixes for defects an independent review found in 9.0.0, counting accuracy first.

- **Half-written lines.** A log line a tool was still writing when TokenBar read the file could be taken as finished and lost; a quiet half line is now left for the next read and counted once it is complete.
- **Pi and oh-my-pi.** Lines are read as JSON instead of matched as text, so spaced JSON, a content field named `model` and nested tool results no longer hide or invent calls.
- **Codex: model named later.** When Codex names the model after the first call of a session, that call is now given the model instead of staying "unknown" (and unpriced).
- **Prices: the live catalogue wins.** A model that OpenRouter lists live is priced from that row, not from TokenBar's small hand-checked table; nine table rows that had drifted were corrected, and `update-prices.py --check-drift` reports any new drift.
- **Prices: cache keeps exact ids.** The daily price cache now keeps every catalogue's exact model ids, so a name priced right after a fresh download is priced the same way from the cache the next day. Tiered prices (for example above 200K tokens) survive the cache too.
- **Prices: aliases.** A `cacheRead` price of 0 in `model-aliases.json` is a real price (free cache reads), not "missing"; an alias may point to another alias (up to four steps, and a loop is left unpriced rather than hanging).
- **Prices: daily refresh while running.** An app left open for days asks for new prices again (it checked only at launch), and going back **Online** refreshes at once.
- **Very long model names.** A model name of tens of thousands of characters could stall pricing; names over 256 characters are left unpriced and the rest are priced in linear time.
- **Compressed logs (`.zst`).** Unpacking stops at 64 MiB for one line and 4 GiB in all; an archive over the limit is named as a problem and not unpacked again.
- **Antigravity.** The newest calls still waiting in the database's `-wal` file are counted. Antigravity, Zed and opencode databases whose `-wal` file is gone open without an error.
- **Crush and Devin dates.** Times written as ISO text show on the right day instead of 1 January 1970. Calls that 9.0.0 already stored as 1970 (Crush, Devin, Copilot Chat, Cline) are read once more after the update and get their real date, on the Mac and on Windows, without being counted twice.
- **Databases next to a `-wal` file.** A `-wal` file that cannot be copied is now a named problem and the database is read again later, instead of being marked as read without its newest calls. When a tool writes to Antigravity or Zed while TokenBar reads it, the new calls are picked up at the next pass. On Windows a cleanly closed database (no `-wal`, or an empty one) is read in place instead of failing.
- **Codex after the update.** A session 9.0.0 had read before its model was named gets the model the first time 9.0.1 reads it.
- **Prices: same answer from the cache.** A model priced after a fresh download is priced exactly the same from the cache (route variants such as `:nitro` and ids that differ only in case no longer shift to another catalogue). The cache format moved to version 2: the first refresh after the update downloads each catalogue in full once.
- **Prices: aliases the same on both systems.** Windows now follows an alias chain of up to four steps like the Mac, an alias loop is unpriced on both, and a `null` price in `model-aliases.json` or in a catalogue tier means "not given" instead of $0.
- **Command line.** `--offline`, `--prices-now` and `--refresh-prices` (the Windows spelling) are accepted.
- **Windows: Claude Code totals.** A run whose start time carried a fraction of a second was counted twice, and a cost record with no session id added a phantom adjustment. A run is now whole seconds and such a record is skipped, as on the Mac. An index made by 9.0.0 is repaired the first time 9.0.1 starts.
- **Windows: databases with a `-wal` file (opencode, Antigravity, Zed, Crush, Goose, Devin).** When TokenBar's private read-only copy of such a database could not be opened, it quietly read the `.db` without its `-wal` and marked the file as read, so the newest calls were never counted. It now reports the problem and reads the file again.
- **Windows: changes in those databases are no longer missed.** The `.db` and the `-wal` each get their own stamp (inode, size, modification time to the nanosecond), compared for equality, so a restored backup, a clock set back or two files that traded times are read again. Each database is read once more after the update, without counting anything twice.
- **Windows: Codex, Qwen and the other readers.** A forked Codex session whose first record had no id no longer loses its calls; a token record without a time is no call. A Qwen usage file that was locked at the wrong moment is named and caught up at the next pass instead of leaving its usage uncounted. Copilot Chat and Cline CLI times written as ISO dates are read; Cline provider names that start with `/` are right; Crush, Goose, Zed and Qwen details match the Mac.
- **Windows: same rules as the Mac.** Pi and oh-my-pi lines are read as JSON; a Codex call written before its model was named gets the model; `.zst` logs have the same 64 MiB / 4 GiB limits; `--prices-now` is accepted and, like on the Mac, skips the one-day wait. On both systems a later read of a call without a model name no longer replaces the model it already had.
- **Windows: very long folders.** Log files below a path of 260 characters or more are found even when the folder you point TokenBar at is short.
- **Windows: window and tray.** The window no longer stops updating after a single internal error, a slow earlier period can no longer overwrite the period you picked, the tray tip and an open window refresh when new prices arrive, a failed price fetch is retried within an hour (not six), the **⋯** menu no longer leaks memory each time it opens, and `TokenBar.exe` with an unknown option prints an error instead of opening the window.
- **Release.** `scripts/release.sh` first audits the repository: clean and pushed, the tag not made yet, and `VERSION`, the Windows version and the changelog all agree. CI now builds and checks the macOS release package (universal build, no build paths in the binary, signature, zip) and the Windows console mode; the Windows zip includes `docs/HARNESSES.md`; the release tag name no longer reaches a script as text.

## 9.0.0 — 2026-11-23
First open-source release (MIT).

- **Windows.** A Windows 10/11 tray app (`windows/`, Python) reads the same tools with the same price rules and gives the same totals as the Mac app on the shared made-up home folder; built and tested on GitHub's Windows runners (`.github/workflows/windows.yml`). Download `TokenBar-Windows-9.0.0.zip` from Releases. Not code-signed: SmartScreen asks once (More info → Run anyway). See `windows/README.md`.

- **Automatic tool detection.** TokenBar now finds the AI coding tools on your Mac by itself: 26 are counted from their local logs (Claude Code, Codex, opencode, oh-my-pi, Qwen Code, Kimi Code, Devin, Antigravity, Crush, Goose, Factory Droid, Amp, OpenHands, Gemini CLI, Pi, GitHub Copilot CLI, Junie, Codebuff, Mistral Vibe, Augment, Cline, Roo Code, Kilo Code, GitHub Copilot Chat, Continue, Zed). Eight were checked against real data; the rest are written from the tools' file formats and tested on a made-up home (see `docs/HARNESSES.md`). Tool locations follow the tools' own environment variables.
- **Tools that cannot be counted are named, not guessed.** Cursor, Windsurf, Trae, Kiro, Warp and Amazon Q are listed as detected; their logs hold no token counts.
- **Your own sources.** `~/.config/tokenbar/custom-sources.json` adds a tool whose files an existing reader understands.
- **Run-time price engine.** Prices come from three public catalogues, OpenRouter, LiteLLM and models.dev, plus a small hand-checked table for models none of them lists. LiteLLM and models.dev (MIT) ship as an embedded snapshot, so the first launch is already priced; OpenRouter is read from the network only. Each catalogue is refreshed at most once a day (one anonymous static GET, 24 hour cache, ETag), never when `TOKENBAR_OFFLINE=1` or **Offline** is on. The menu has **Update prices** and **Offline**. Model names fold the same way everywhere (provider path, `:free`, dates, `.`/`_`/`-`).
- **Local model rule.** A model that runs on your machine is priced as its cloud counterpart when one exists and costs nothing when none does. A cloud model is never free: a free-only model takes the price of its nearest paid model, and the breakdown says which and why. A model with no source stays "no price"; nothing is invented.
- **Your own price names.** `~/.config/tokenbar/model-aliases.json` prices names no catalogue knows (a home server, a routing chain, a quantised copy), with an optional note and a `near`/`other` mark.
- **Readable model names.** A model a catalogue lists without a name shows as "Claude Mythos 5.2" or "GPT-6.2 Sol" instead of its raw id.
- **Free-only routes priced:** Nemotron 3.5 Bolt E4B and Super VL (120B A12B spelling), Flint 40B, ERNIE-5.5-Flash-Preview, Gemini 4 Argon (trial plan).
- **Two languages.** English and Turkish interface, chosen by the system language; `TOKENBAR_LANG=en|tr` overrides it.
- **Open source.** MIT licence, `PRIVACY.md`, contribution guide and code of conduct, English and Turkish READMEs, no telemetry. The only network traffic is the price-catalogue GETs above.
- **Packaging.** `scripts/build-app.sh` builds an ad-hoc signed `TokenBar.app` (arm64, or `--universal`); `scripts/release.sh` makes the zip, its SHA-256 and release notes; a Homebrew cask template is in `packaging/homebrew`. The app is not notarized, so the first launch needs the Gatekeeper step in the README.
